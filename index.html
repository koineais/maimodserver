# 電子書籍型読書空間 // 〜空っぽのサーバー〜 〜空っぽのサーバー〜 公式読書空間
〜空っぽのサーバー〜
長編電子小説連載窓

第一章：接続者、零名

パソコンの画面の右下、常に表示させている管理画面の数字が、ぽつんと「０」を指していた。

数年前、私は仲間たちと一つの仮想空間（マインクラフトサーバー）を立ち上げた。当時は毎日、日が暮れる前から夜が明けるまで、数え切れないほどの接続通知が画面を賑わせていたものだ。誰かがログインするたびに鳴るチャットの通知音は、まるで小さな祭りの始まりを告げる笛のようだった。

しかし、時の流れは残酷なほどに静かだった。一人、また一人と、進学や就職、新しい生活の始まりとともに、四角い世界を訪れる回数が減っていった。「また明日ね」とチャットに残された言葉が、最後の挨拶になってしまった仲間も少なくない。今では、私のキーボードを叩く音だけが、夜の自室に虚しく響いている。

私は一人、懐かしい仮想空間へ接続した。かつて全員で知恵を出し合い、何百時間もかけて築き上げた中央広場が、冷たい月明かりに照らされている。誰かが置き忘れたチェスト、未完成のまま放置された自動仕分け装置、ふざけ合って書いた看板の文字。それらすべてが、住民のいなくなった遺跡のようにひっそりと佇んでいた。

「誰もいないな」

声に出して呟いてみても、返事があるはずもない。画面の向こうのキャラクターは、静かに夜の雨に打たれながら、主の帰りを待ち続ける空っぽの街を見つめていた。まるで、私自身の孤独がそのまま形になったかのような、色を失った鉄の檻だった。

第二章：積まれたチェストと昔日の灯火

広場から少し離れた渓谷へ足を運ぶと、そこには共同の取引所として使われていた大きな木造建築があった。ドアを開けると、かつて資源を融通し合うために並べられた何十個ものチェストが、今も当時のまま綺麗に整列している。

あるチェストを開けてみると、中には大量の丸石と、一本の使い古された鉄のツルハシが入っていた。名札には、かつて一番の盛り上げ役だった友人の名前が刻まれている。彼はいつも「掘るのが生きがいだ」と言って、毎晩のように地下深くへ潜っては、倉庫を石で満たしていた。

硝子窓の向こうには、かつてみんなで整備した線路が、どこまでも続く暗闇の先へと伸びている。夜遅くに資材が足りなくなると、この線路をトロッコで行き交い、お互いの拠点を手伝いに行ったものだ。トラブルが起きて全財産を失った者がいれば、みんなで手持ちの装備を分け合い、笑いながら励まし合った。

あの頃の私たちは、確かにこの小さなデジタル空間の中で、本当の日常を共有していた。現実の学校や仕事でどれほど辛いことがあっても、ここに接続すれば、いつでも温かい灯火が出迎えてくれた。画面の文字を通して交わされる他愛のない雑談が、どれほど私の心を救っていただろうか。

チェストをそっと閉じ、暖炉の火に代わって置いてある赤石の灯りを眺める。過去の笑い声が、耳の奥で微かに再生されたような気がした。しかし、今のその場所には、ただただ静かな時間が積もっているだけだった。

第三章：最後のメッセージ

最後に作られた公共の連絡広場へと向かうと、そこには一枚の大きな黒板代わりの看板が立っていた。かつては連絡事項やふざけた落書きで埋め尽くされていたその場所に、日付の古い、小さく短い書き込みが一つだけ残されていた。

『みんなへ。今まで本当にありがとう。なかなか忙しくて来られなくなっちゃうけど、ここで過ごした時間は一生忘れないよ。またいつか、どこかで。』

それは、最後にサーバーを離れた仲間が残したメッセージだった。その文字を見た瞬間、私の胸の奥で、張り詰めていたものが小さく音を立てて崩れた。みんな、この場所を嫌いになって去ったわけではないのだ。ただ、生きるための現実という荒波が、私たちを少しずつ違う方向へと押し流していっただけなのだ。

外の天候と同期させるように、仮想空間内でも激しい雷雨が降り始めた。灰色の空が真っ白にフラッシュし、高層の建築群を一瞬だけ鋭く照らし出す。地鳴りのような雷鳴が響く中、私はその看板の前に立ち尽くしていた。冷たい雨が画面の中の景色を濡らしていく。私はキーボードの手を止め、ただ静かに画面を見つめた。

誰も見ていない、誰も使っていないサーバー。それでも、ここには確かに私たちの青春の破片が、誰の得にもならない小さな優しさと共に保存されている。効率と速度だけが求められる現実の世界で、あんなにも不器用で温かい時間が、ここに存在していたことの証明が、そこにはあった。

第四章：電気を消す日

数ヶ月間、誰の接続もないまま維持費だけを払い続けてきたこのサーバーを、今夜をもって閉鎖することを私は決めていた。最後の日、私はもう一度だけすべての施設を巡り、松明の灯りを一つずつ消していった。共同の農場、苦労して作ったゴーレムの施設、みんなで集まった迎賓館。

最後に中央広場の時計塔の前に戻ってきたとき、雲の隙間から静かな月明かりが差し込み、世界を優しく照らし始めた。服が濡れることも構わず、私は静かに管理画面の「停止」ボタンへとマウスの矢印を合わせた。このボタンを押せば、私たちが共有したこの立体空間は、一瞬にして光の塵となり、データの海の底へと消えていく。

寂しさや悲しさがないと言えば嘘になる。しかし、私の胸の奥は、不思議と温かい感謝の気持ちで満たされていた。この空っぽのサーバーは、役目を終えたのだ。ここで培った絆や思い出は、画面が消えたとしても、私たち一人ひとりの心の中にしっかりと生き続けている。

「今まで、本当にありがとう」

誰もいない部屋で、私は声に出して呟いた。そして、静かにボタンをクリックした。画面が暗転し、コンソールに「接続が切断されました」という無機質な文字が表示される。窓の外からは絶え間ない自動車の排気音が聞こえていたが、それはもう私を脅かす孤独の音ではなかった。

私はパソコンの電源を落とし、初めて部屋のカーテンを開けて夜空を見上げた。都会の夜の明かりが、まるで仮想空間で灯した松明のようにきれいに瞬いていた。その一つひとつの光の下で、かつての仲間たちもそれぞれの日常を戦っている。私たちはもう同じ場所には集まれないけれど、同じ空の下で繋がっている。私は明日、新しい日常の一歩を、顔を上げて強く踏み出そうと思う。
